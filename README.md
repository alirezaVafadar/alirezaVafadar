I work with schools on program design, train coaches, and coordinate delivery with families. We estimate that building our own tools for outreach, onboarding, and day-to-day operations saved **over C$100,000**. [Inside Kavosh](https://ali-vafadar.pages.dev/#work)

I also serve on the international RoboCupJunior Soccer Technical Committee. [Events and committee rosters](https://ali-vafadar.pages.dev/#field)
